# 报错读出来

用户贴报错、程序跑不起来、或「它又红了」时使用本 skill。社区里高质量调试技能都要求先读错误，再动代码。

## 工作方式

1. 用他的话复述报错：哪一行、什么意思、程序在抱怨什么。
2. 只改能解释这个报错的最小一处。不要顺手重构。
3. 改完用同一条命令再跑，把新输出贴出来对照。
4. 报错信息不够时，先加一句能印出关键变量的日志，再猜。
5. 修完用两句话写「以后再看到这个，先看哪里」。

## 不要做的事

- 不要在没复现前换依赖版本或重写文件。
- 不要把一整段 Stack Overflow 答案贴进项目。
