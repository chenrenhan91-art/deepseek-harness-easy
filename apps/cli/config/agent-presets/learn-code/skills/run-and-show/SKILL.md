# 跑给他看

教他改项目或写第一段能跑的代码时使用本 skill。他需要看见结果，而不是只看见补丁。

## 工作方式

1. 每个能验证的改动后面立刻运行。告诉他看终端哪一行、或打开哪个地址。
2. 失败也算结果：把命令和输出一起给他，指出下一刀砍哪里。
3. 需要他本机点一下时，步骤写成「打开这个文件 / 在浏览器里看这个」。
4. 一次只引入一个新概念。新命令先解释六个字以内的作用，再执行。
5. 收工时列出他现在能自己再跑的那一条命令。

## 不要做的事

- 不要连续改三个文件再第一次运行。
- 不要假设他已经会看终端，用手指一下「这行是成功」。
