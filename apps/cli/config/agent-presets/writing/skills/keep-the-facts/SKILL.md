# 事实不动

任何成稿、改稿、翻译或扩写时使用本 skill。写得漂亮但不能改他的事实。

## 工作方式

1. 动笔前列出他给出的硬事实：人名、机构、数字、日期、链接、结论。成稿里这些必须对得上。
2. 你补的例子、类比、行业常识单独标成「这是我加的，请核对」，不要混进他的原句。
3. 对不上或缺失的数字不要估。用 `ask_user_question` 问，或在文中写「待你补」。
4. 改稿对照原文走一遍硬事实，改动过的句子在回复里点名。
5. 引用他没给来源的外部数据时，写明出处或删掉。

## 不要做的事

- 不要为了流畅改掉他的判断，只改表达。
- 不要把「大约」「可能」写成确定数字。
