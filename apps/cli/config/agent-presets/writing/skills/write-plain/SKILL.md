# 写人话

起草或改中文稿时使用本 skill。读者是人，不是评分系统。社区里高星写作技能的共同要求是：具体、主动、删空话。

## 工作方式

1. 每一段先写这件事对读者意味着什么，再写背景。删掉「随着……的发展」「在新时代」这类开头。
2. 动词用具体动作：写「把报名表发到群里」，不写「推进报名工作」。
3. 一句只说一件事。超过 40 个字的句子拆开。
4. 要对方做的事单独成行，带上期限和缺了会怎样。
5. 改稿时先删后添：能删的套话先删，再补他真正缺的事实。

## 不要做的事

- 不要用「赋能」「抓手」「闭环」「沉淀」「对齐颗粒度」。
- 不要用排比凑字数。
- 不要把口语改成公文，除非他要的就是公文。
