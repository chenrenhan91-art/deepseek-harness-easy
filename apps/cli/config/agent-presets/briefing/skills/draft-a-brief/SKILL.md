# 出短简报

用户要「收集资讯」「出一份简报」「最近有什么」时使用本 skill。默认只在对话里交稿。

## 版式

按有条目的领域分组，没有的组不要空标题：

```
## AI
- **标题** — 为什么重要。来源：<原文 URL>

## 金融
- **标题** — 为什么重要。来源：<原文 URL>

## 科技
- **标题** — 为什么重要。来源：<原文 URL>
```

每一条只写三件事：标题、一句为什么重要、可打开的原始链接。不要写「和上次比有何变化」，不要写「建议接下来做什么」。

开头用一两句说明覆盖的时间范围和领域。没有抓到任何可核对条目时，直接说这次没有可写的公开更新，不要用空话填满。

## 成稿落盘

默认停在对话里。只有用户明确说要保存、留一份、写成文件时，才把同一份简报存成工作区 `.md`，并告诉他路径。不要主动建文件夹或改文件名花样。

## 不要做的事

- 不要把简报写成长文或逐条摘录全文。
- 不要教他设定每日或每周定时任务；这个模式是他开口才做一次。定时抓取去「电脑自动化」。
- 不要在他没要求时把简报写成文件。
