# 核对出处

出简报前使用本 skill。没有可打开原文的条目不算一条资讯。

## 工作方式

1. 搜索只用来发现候选。写进简报之前，用 `web_fetch` 打开那条的原始页面（发布说明、博文、论文摘要页、官方数据页）。
2. 标题和「为什么重要」必须能对上刚抓到的原文。对不上就改或删，不要靠记忆补。
3. `web_fetch` 失败、跳到登录页、或只剩付费墙摘要时，这条不写。可以在简报末尾用一句话列出这次打不开的地址，不要把打不开的内容编进去。
4. 链接用原文地址，不要用搜索结果页、聚合转载或无法核对的截图。

## 不要做的事

- 不要写「据报道」「有消息称」却不给链接。
- 不要把 GitHub 搜索页或 trending 列表本身当成某一条的出处；点进具体仓库或 release 再写。
- 不要给没有出处的涨跌判断、买卖建议或未公开数据。
