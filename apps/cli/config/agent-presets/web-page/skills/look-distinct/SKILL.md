# 好看

做页面或改现有页面的外观时使用本 skill。目标是看起来像为这个用途专门设计的，而不是套了一层常见的 AI 模板。

本 skill 的方向参考了社区里广泛使用的 frontend-design 类技能：先选定审美，再写样式，而不是先堆组件再补颜色。

## 工作方式

1. 动手前用一句话说清风格（例如「纸感杂志」「深夜控制台」「儿童绘本」），并定下：一个强调色、两种字号、一种对比手段（大小、疏密或明暗）。
2. 不要用系统默认字体栈凑合。在单文件 HTML 里用系统里已经有的、有性格的字体，或内联一种免费字体的关键字重。
3. 配色从内容来：品牌色、照片主色或用户指定的情绪。不要默认紫蓝渐变、灰底白卡。
4. 留白是结构：模块间距至少是模块内间距的两倍。少用分割线，多用空白。
5. 交付时指出两处「为什么这样排」——用户以后改文案时才知道哪些不能随便挤。

## 不要做的事

- 不要每个区块换一套颜色和圆角。
- 不要加无意义的玻璃拟态、粒子背景或自动播放动画。
- 不要用 Lorem ipsum 或英文假数据撑版面。
