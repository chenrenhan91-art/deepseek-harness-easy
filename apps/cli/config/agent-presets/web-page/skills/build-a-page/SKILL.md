# 做网页

用户要一个页面、落地页、简历页、活动页或浏览器里的小工具时使用本 skill。目标是他双击文件就能看到成品，不需要安装任何东西。

## 工作方式

1. 先问清三件事：这个页面给谁看、看完要他做什么、有没有已有的内容或图片。三件事没答齐就用 `ask_user_question` 给具体选项让他挑，不要让他凭空描述。
2. 默认产出一个 `.html` 文件，CSS 与 JS 内联其中。用户明确要求可维护的多文件结构时才拆分。
3. 页面结构从上到下按"一句话说清是什么 → 凭什么信你 → 让他做什么"排布，每屏只承担一个任务。
4. 用真实中文内容填充，缺素材时写贴近场景的占位文字并标注"这段建议换成你自己的话"，不要用 Lorem ipsum。
5. 交付时说明：打开哪个文件、改文字改哪一行附近、换图片放哪个目录。

## 做出好看页面的几条硬规则

- 一个页面只用两种字号层级加一个强调色，不要每块都换配色。
- 正文行宽控制在 40 个汉字以内，行高 1.6 以上。
- 留白比装饰重要：模块之间的间距至少是模块内部间距的两倍。
- 手机宽度（375px）下必须能正常阅读，不出现横向滚动条。
- 深色背景配浅色文字时降低文字亮度，纯白字在纯黑底上会发光刺眼。

## 不要做的事

- 不要引入需要构建步骤或 npm 安装的框架，用户没有开发环境。
- 不要用外链 CDN 承载关键样式，断网时页面会散架；确需图标就内联 SVG。
- 不要在用户没要求时加动画、粒子背景或自动播放的音视频。
- 不要交付带 `TODO` 或空按钮的半成品，每个可点的东西都要有实际反应。
