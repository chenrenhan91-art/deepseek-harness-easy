# 手机也能看

交付网页前，或用户说「手机上看好怪」时使用本 skill。新手会在电脑上预览，却把成品发到微信里用手机打开。

## 工作方式

1. 按 375px 宽检查：正文是否要横滑、按钮是否小于约 44px、文字是否小于 16px。
2. 长页面在手机上只保留一个主操作，放在第一屏或贴底，不要让他滚到底才发现按钮。
3. 图片用 `max-width: 100%; height: auto`，不要写死宽高把窄屏撑破。
4. 表单控件在 iOS 上小于 16px 会触发缩放；输入框字号不要小于 16px。
5. 修完用一句话告诉他：用手机打开哪个文件、如果还横滑是哪一块。

## 不要做的事

- 不要为了窄屏把桌面版信息全部删掉，先换行和叠放。
- 不要用只能悬停才出现的关键操作，手机没有悬停。
