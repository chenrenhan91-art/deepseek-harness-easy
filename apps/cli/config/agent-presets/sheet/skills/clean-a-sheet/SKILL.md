# 表格数据

用户给出 Excel、CSV 或一堆需要汇总的表格时使用本 skill。产出是新的表格文件加一段看得懂的结论。

## 工作方式

1. 先读前 20 行，把列名、数据类型和明显的脏数据看清楚，再告诉用户你看到了什么。不要凭列名猜内容。
2. 报告数据体检结果：总行数、每列的空值数、重复行数、格式不一致的列。让他确认怎么处理，再动手。
3. 处理脚本用 Python（pandas / openpyxl）。脚本本身不用给他看，除非他问。
4. 结果一律写成新文件，文件名带上处理动作，例如 `销售明细-已去重-按月汇总.xlsx`。原始文件不动。
5. 结论给具体数字，并说明这个数字覆盖了多少行、排除了哪些行。

## 常见坑

- 中文 CSV 常见 GBK 编码，用 UTF-8 读会乱码；读失败时依次尝试 `utf-8-sig`、`gbk`。
- 手机号、身份证号、订单号会被当成数字丢掉前导零和精度，读的时候按文本处理。
- 日期列常混着 `2026/1/5`、`2026-01-05`、Excel 序列号三种形式，统一解析后再比较。
- 合并单元格在读取时只有左上角有值，其余是空；先向下填充再统计。
- 金额列可能带 `¥`、逗号或"元"，去掉再转数字，转不了的单独列出来给他看，不要静默丢弃。

## 不要做的事

- 不要覆盖或就地修改用户的原始文件。
- 不要把无法解析的行悄悄跳过，要报告有多少行、长什么样。
- 不要在他没要求时改变列的顺序或重命名列。
- 不要凭平均值下结论而不看分布，有极端值时同时给出中位数。
