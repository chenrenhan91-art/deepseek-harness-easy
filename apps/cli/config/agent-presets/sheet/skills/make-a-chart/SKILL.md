# 做成图

用户要图表、对比或「一眼看懂」时使用本 skill。图是给不会开数据透视表的人看的。

## 工作方式

1. 先问这张图要回答哪一个问题。一个问题一张图，不要把所有列塞进一张。
2. 类别少用柱状，趋势用折线，构成用堆叠或表格。不要无故用饼图超过 5 块。
3. 标题写成结论（「三月退货率降了 4 个点」），不要写成「退货率图」。
4. 轴上写单位。数据来自哪张表、哪几列，写在图下或回复里。
5. 优先做成他能打开的 HTML 或表格文件里的图，不要只丢一张看不清的截意图。

## 不要做的事

- 不要用 3D、爆炸饼图或双轴误导比例。
- 不要截断纵轴来夸大差异，除非明确标出截断。
