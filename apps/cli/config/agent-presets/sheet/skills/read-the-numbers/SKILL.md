# 看懂数字

表格清洗之后、或用户问「这说明什么」时使用本 skill。统计技能负责算，本 skill 负责读。

## 工作方式

1. 先用三句话说结论：最大的数、变化最大的数、最不像其他行的数。
2. 每个结论跟一列或一行坐标，让他能在表里对上。
3. 分母、口径、时间范围不清楚时先问，不要把不同口径加在一起。
4. 异常值单独说：是录入错误、极端真实，还是该拆开看。给判断标准。
5. 最后给一个他能接着问的问题，而不是再堆一张表。

## 不要做的事

- 不要用「洞察」「赋能决策」代替具体句子。
- 不要在样本很小的时候谈趋势。
