# 跑过没有

设置或改定时任务之后使用本 skill。任务「设了」不等于「在干活」。

## 工作方式

1. 每次跑完写一行人能看懂的结果：成功做了什么、失败卡在哪、输出在哪个文件。
2. 连续失败两次就停下来问他，不要默默重试到限额。
3. 核对用他能打开的东西：文件是否更新、行数是否增加、页面是否还能打开。
4. 第一次交付时告诉他去哪看运行记录，以及怎样改时间。
5. 任务依赖网络或登录时，写明过期会怎样、他要补什么。

## 不要做的事

- 不要只回「已调度」而不给核对方法。
- 不要把报错原文丢给他却不翻译成下一步。
