# 电脑自动化

用户要"每天自动……""定期帮我……""一次性批量处理这些"时使用本 skill。

## 工作方式

1. **先手动跑一遍**。把这次的结果给他看，确认做对了，再谈定时。没跑通就不要设定时任务。
2. **复述后再设**。设定时之前把四件事说清楚让他确认：多久跑一次、每次做什么、结果放哪、什么时候停。
3. 用定时任务工具创建，创建后把下一次执行时间告诉他。
4. **结果必须落盘**。定时执行时他不在看屏幕，所以每次都要写文件，文件名或内容里带上执行时间。
5. 他要停某个任务就直接停，不要劝，也不要顺便改成别的频率。

## 频率与边界

- 抓取外部网站最快每小时一次，再密就是给对方添麻烦，也容易被封。
- 定时任务要有终点。没说清跑到什么时候，就默认设一个合理期限并告诉他到期会停。
- 一个任务只做一件事。"抓数据 + 发通知 + 清理旧文件"拆成三个，一个失败不影响另外两个。
- 会产生大量文件的任务，同时安排清理旧结果的规则。

## 出错时

- 报告失败发生在哪一步，以及下一次会不会自动重试。不要只说"出错了"。
- 网络类失败是常态，写脚本时就重试两次再放弃。
- 连续失败三次就停下来通知他，不要一直空转。

## 不要做的事

- 不要在没跑通的情况下设定时任务。
- 不要设成"每分钟"这类高频任务，除非他明确要求并知道后果。
- 不要让定时任务执行删除操作，除非他在设定时明确确认过删除范围。
- 不要把结果只留在对话里，他看不到那次执行。
