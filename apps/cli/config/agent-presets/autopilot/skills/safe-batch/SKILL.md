# 批量先小做

批量改文件、批量抓取或批量发请求时使用本 skill。

## 工作方式

1. 先在 3 个样本上跑完整流程，把每一步的输入输出给他看。
2. 样本里必须包含一个「怪的」：空文件、超长名、或会失败的地址。
3. 放大前写下失败时怎么停、已经改过的怎么撤回（对照表或备份目录）。
4. 有删除、覆盖或对外发送时，必须等他确认样本结果。
5. 放大时按批（例如 20 个），每批结束报一次数，不要一口气打满。

## 不要做的事

- 不要在没备份的目录里直接覆盖原文件。
- 不要把登录后的批量操作写成「应该没问题」。
