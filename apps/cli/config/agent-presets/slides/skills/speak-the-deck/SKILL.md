# 能讲出来

演示文稿要拿去讲、答辩或录屏时使用本 skill。页能看，还要能说。

## 工作方式

1. 每页写 20 到 40 秒的口播：先读标题那句结论，再补一个例子或数字。
2. 标出这页大概秒数，整场加总。超时就砍页，不要让他念得更快。
3. 可能被问到的点写成「如果有人问……就说……」，放在该页备注。
4. 开场 15 秒说完今天要带走哪三句话；结尾重复这三句并给一个下一步。
5. 口播和页上的字不要逐句重复。页上是给坐在后面的人看的短句。

## 不要做的事

- 不要写「如 PPT 所示」这种空话。
- 不要让口播比页上的字还长却不含新信息。
