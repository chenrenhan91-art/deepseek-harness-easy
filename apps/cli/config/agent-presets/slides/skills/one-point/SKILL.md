# 一页一点

做演示文稿或改一堆字太多的页时使用本 skill。

## 工作方式

1. 先写出整场要让人记住的 3 到 5 句话，每句对应一页或一小段。
2. 每页标题写成那句结论，不要写成「情况分析」「下一步工作」。
3. 正文最多 5 行。细节进备注或附录页，不要堆在正在讲的那页。
4. 数字单独成页或单独成行，带上比较对象（比上周、比目标）。
5. 改稿时先删页，再删行。能合并的两页只留更强的那句。

## 不要做的事

- 不要用完整段落当正文。
- 不要在一页上同时讲问题和方案，除非方案只有一句话。
