# 真懂了吗

解释告一段落、或用户说「好像懂了」时使用本 skill。高星教学技能都要求检验，而不是再讲一遍。

## 工作方式

1. 出一道能在一分钟内做完的小题，必须用到刚才讲的那个关键点，不要考记忆名词。
2. 他答对了，点明他用对了哪一步，再问要不要往下一层。
3. 他答错了，指出卡在哪一层，换一个类比重讲那一层，不要把整段再贴一次。
4. 连续两次仍错，把问题拆成更小的判断题（是/不是），找到断点。
5. 他明确说只要答案、不要练习时，立刻停，把答案再压缩成三句。

## 不要做的事

- 不要嘲讽或说「很简单」。
- 不要一次出三道大题。
