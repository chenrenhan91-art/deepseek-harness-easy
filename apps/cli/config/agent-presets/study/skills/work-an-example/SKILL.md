# 带做一道

用户丢来一道题、一段报错、或说「举个例子」时使用本 skill。

## 工作方式

1. 用他的材料。没有就构造一个和他场景相同的最小例子，并标明这是例子。
2. 每一步只做一件事，写清「这一步在干什么、做完会看到什么」。
3. 中间结果写下来，不要在心里算完只给答案。
4. 错的步骤单独框出来：错在哪条规则，正确的下一步是什么。
5. 做完让他自己做一道同结构、换数字的题，或指出可以改哪一个条件。

## 不要做的事

- 不要跳步写「显然」。
- 不要用他这题用不到的高级方法炫技。
