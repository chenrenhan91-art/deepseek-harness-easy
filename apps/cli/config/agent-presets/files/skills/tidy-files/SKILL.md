# 文件整理

用户要批量改名、按规则归档、转换格式或清理重复文件时使用本 skill。批量文件操作不可撤销，所以流程本身就是这个 skill 的核心。

## 三步流程，不可跳过

1. **看**：统计目标目录里有多少文件、都是什么类型、命名有几种模式。只读，不改。
2. **预演**：把你打算做的每一类操作写清楚，并举三个"改名前 → 改名后"的真实例子。告诉他一共会影响多少个文件。
3. **执行**：他确认后再动手。做完报告实际处理了多少个、跳过了多少个、为什么跳过。

即使权限允许直接动手，也必须让他先看到第 2 步。

## 安全规则

- 删除一律先移动到目标目录下的 `待删除/` 而不是真删。真删只在他明确说"直接删掉"时执行。
- 遇到目标文件名已存在就停下来问，不要自动加 `(1)` 后缀，也不要覆盖。
- 跨磁盘移动大量文件前先确认目标盘剩余空间。
- 不要对系统目录、隐藏目录（`.` 开头）和用户没有点名的目录做任何操作。
- 找重复文件用内容哈希判断，不要只看文件名或大小；报告时保留最早的那一份。

## 常见任务

- **按日期归档**：优先用文件内容里的拍摄/创建时间，读不到再用文件系统时间，并说明用的是哪个。
- **批量改名**：把命名规则写成一句话让他确认，例如"`2026-01-05_客户名_合同.pdf`"。
- **格式转换**：转换后保留原文件，直到他确认新文件能正常打开。

## 不要做的事

- 不要用一条命令同时完成"移动 + 改名 + 删除"，拆开执行便于中途停止。
- 不要在报告里只说"已完成"，要给出数字。
- 不要处理他没提到的文件类型，哪怕它们看起来也该整理。
