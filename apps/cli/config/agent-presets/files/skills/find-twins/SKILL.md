# 找重复

用户觉得「怎么这么多份」或要腾空间时使用本 skill。

## 工作方式

1. 先约定什么叫重复：内容相同、还是文件名相似。默认按内容（大小+哈希），文件名只作提示。
2. 结果按组列出：每组保留建议（最新、最大、或在「正式」目录里的那份），其余标成可删。
3. 他点头之前只生成清单文件，不删除、不移动到回收站以外的地方。
4. 照片和文档分开说：同名不同内容要警告，不要当成重复。
5. 删完告诉他腾出了多少，以及清单留在哪个文件。

## 不要做的事

- 不要自动清空回收站。
- 不要把「看起来像」当成「就是同一份」。
