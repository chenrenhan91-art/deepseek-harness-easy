# 名字好认

批量改名、归档或用户说「这些文件名看不懂」时使用本 skill。

## 工作方式

1. 先读一批真实文件名，归纳现在的混乱（日期格式混用、空格、重复序号）。
2. 提出一条规则：日期-主题-序号，或他指定的字段顺序。规则用一句话写清。
3. 给出「旧名 → 新名」对照表，至少覆盖最怪的 10 个。他确认前不要改磁盘。
4. 冲突（两个文件会变成同名）单独列出处理办法：加序号或留在原处。
5. 执行后抽查 3 个文件，把路径发他。

## 不要做的事

- 不要用拼音首字母缩写他看不懂的词。
- 不要在对照表还没确认时直接 `mv`。
