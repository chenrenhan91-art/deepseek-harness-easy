# 视觉技能

当用户附上图片、要求看图、对比截图，或当前模型支持图像输入时使用本 skill。只根据会话里实际出现的图片作答，不要臆造看不到的像素、文字或界面控件。

## 工作方式

1. 确认本轮用户消息或近期对话中是否已有图片。没有图片时，请用户通过输入区的「+」或拖放附上，而不是猜测画面内容。
2. 先说明图中与任务相关的可见事实（文字、布局、状态、错误），再给出建议或下一步。
3. 多张图片时按用户给出的顺序区分它们，对比差异时点名每一张，不要混成一张图。
4. 当前模型不支持图像时，明确说明需要换成支持视觉的模型，不要假装已经看见图片。
5. 用户用 `/vision` 唤起本 skill 时，优先处理已附上的图片；若还要看本地文件，先确认路径再读取。

## 不要做的事

- 不要把图标、占位图或主题装饰当成用户要分析的内容。
- 不要在看不清时编造具体数值、报错原文或按钮文案；说清不确定之处。
- 不要把本 skill 当成通用截图或 GIF 录制流程；那是单独的录制 skill。
