什么是 Harness

什么是 DeepSeek Harness

DeepSeek Harness 是 DeepSeek 开源的智能体运行时。它不只在窗口里说话：模型可以读你选中的文件夹、改文件、跑命令、上网查资料、按 skill 做事。底层用一套叫 Cordis 的插件框架，模型适配、工具、会话、循环本身都是插件，没有一块改不了的内核。

官方仓库给开发者改引擎。你桌面上的图标跑的就是这套引擎。MIT 许可，代码在 github.com/deepseek-ai/deepseek-harness。

  1. 01

    聊天框交差交不出去

    网页、表格、改名、定时任务要落在你电脑里。对话框里的「我已经写好了」不是文件。Harness 的工作区就是你选的那一层文件夹。

  2. 02

    能力要能加，不必换一家产品

    新工具、新界面、新策略用插件挂上去，用配置叠上去。不必因为缺一个节点就搬到另一家平台，也不必为了加能力把整份源码改穿。

  3. 03

    关掉再打开，上次还在

    发给模型的内容要能从会话日志还原。刷新页面、隔天再来，不是一段消失的聊天记录。这是产品约定，不是靠记忆力。

三层机制。小白不必会写插件，但值得知道为什么它和聊天窗不是同一种东西。

一切都是插件
模型、文件工具、命令、网页界面、agent 循环都可以替换或卸载。注册会随插件卸走，不会在后台留一套改不掉的核。
用配置叠上去
启动时按层拼出一棵插件树：组合包、本机补丁、命令行覆盖。改行为是改配置行，不是去源码里打补丁。
模型看见的都记在日志里
进模型请求的内容必须能从会话日志重建。新的模型可见输入要写成会话事件。所以它能回放，也能核对「刚才到底看过什么」。

相比别的，优势在干活方式，不在更会聊天

不宣称比某家模型更聪明。差在：东西写在哪、谁说了算、关掉以后还在不在。

普通聊天框

ChatGPT、通义、网页对话

  • 文件在你电脑上工作区里的 html、表格、文稿可以双击打开。聊天框通常只给你一段可以复制的字。
  • 能动手，不只出主意读文件、改文件、跑命令、按 skill 执行。聊天框默认停在建议。
  • 会话能接着、能回放日志在本机。不是每次打开都像第一次见面，也不是平台一清记录就没了。

拖拽搭 agent 的平台

扣子、Coze、Dify

  • 跑在你这台机器上密钥和工作区默认在本机。不是先把流程和文件交到别人的画布上才能跑。
  • 开源，能力用插件加MIT。缺能力就挂插件或改配置，不是只能用平台提供的节点，也不是流程锁在一家商店里。
  • 有沙箱和审批，不是连完就全盘动手文件和命令可以按策略拦住。拖拽编排很容易「看起来自动了」，实际权限边界不清楚。

代码库和编程辅手

LangChain、Agents SDK、Cursor、Claude Code

  • 打开就是产品，不是还要自己拼一层有窗口、会话、工具、权限、桌面图标。LangChain 和 Agents SDK 是给你写程序用的零件。
  • 作业不默认等于改代码Cursor 和 Claude Code 很强，默认把你当程序员。Harness 的作业可以是网页、表格、简报、整理文件夹。
  • 循环、日志、权限是装好的约定不是在笔记本里临时串一条链。模型看见的必须能还原；工具执行走登记过的管道。

这一版 Easy 只是套在引擎外面的小白外壳：八张中文模式卡片、发送时带上做法。引擎仍是官方 DeepSeek Harness。

质量不是靠多说几句。是四道挡板。

左边四步挡住常见坏结果。右边是同一件事的两种纸样：堆满装饰的模板，和能发出去的一页。

01 选模式

先定「你要哪种东西」

做网页不会被当成写作。答疑不会被扩成一课 PPT。模式选错，后面再努力也对不上。

02 钉做法

发送时自动带上 1 到 3 条

标签就是这个模式最常用的做法。点掉这次不带。学习答疑默认只带「讲明白」，避免短问被教成一堂课。

03 交文件

磁盘上要有，口头不算

html、文稿、表格、简报要能打开。助手说「做好了」不算数。网页做完会尝试在浏览器里打开。

04 适配度

做成品时再点 /fit

三句核对：是不是他要的那种、打开后能不能用、有没有多做。不自动钉上，短答不必走这步。

点一个模式，看它挡住什么

右侧三条杠是示意，不是实验室分数。看「聊天框常见结果」和「这一版要交的」差在哪。

两个共用做法，故意不自动带上

八个模式都能在「+」里找到它们。自动钉上会占掉领域标签，短问也会被多教一截。

视觉 /vision

用来看图、对比图、说明图里有什么。没有图就不要点。它不负责做网页好不好看，好看走「好看」这条。

适配度 /fit

用来在交稿前核对自己看见的文件和命令输出。禁止再开一套模型去打分。口头短答跳过。再加共用做法时，必须写进「不要自动钉」的名单，否则会挤掉领域标签。
