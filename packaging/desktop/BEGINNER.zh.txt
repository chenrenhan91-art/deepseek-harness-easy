DeepSeek Harness 使用说明

macOS：不要双击 .command 或 .app（系统会拦截）。把仓库地址发给能跑终端的 AI，按 INSTALL.md / INSTALL.zh.md 安装：
https://github.com/chenrenhan91-art/deepseek-harness-easy

请按仓库里的 INSTALL.md（中文看 INSTALL.zh.md）在这台电脑安装 DeepSeek Harness。克隆、安装依赖、构建，然后执行 pnpm dsh web。不要让我双击 .command、.app，也不要下 Source code zip。

Windows：解压 DeepSeek-Harness-Windows.zip，双击 DeepSeek Harness.exe。若出现 SmartScreen，选「仍要运行」。

浏览器打开 http://127.0.0.1:3080 后，按页去创建 API Key 和官方充值。数据与 Key 在 ~/.dsh，不要提交到 git。
