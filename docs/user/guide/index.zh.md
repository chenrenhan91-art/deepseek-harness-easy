# 使用 Web UI

[English](index.md) | 中文

服务器还没起来时，助手应先按 [INSTALL.md](../../../INSTALL.md) 安装。用 `pnpm dsh web` 或桌面图标启动 Web UI；命令会打印其访问地址。本指南从服务器已经运行的状态开始。`dsh` 进程会把调用目录作为默认文件系统位置，但新的 Web UI 在添加工作区前不会选中任何工作区。

## 配置模型

首次启动且没有任何可用提供方时，整页引导会要求输入 DeepSeek API 密钥，并给出官方「创建 Key」和「充值」链接，先探测再保存。之后工作台若出现 402 / 余额不足，会再次给出官方充值链接。之后可以打开**设置 → 模型**来添加或更改提供方。

[模型配置指南](./providers.md)介绍其他提供方和自定义 OpenAI 兼容端点。

## 选择工作区和模式

点击**选择工作区**，添加启动 `dsh` 时所在的项目目录，然后选中它。选中工作区前，会话输入框不可用。在新会话页上选一张模式卡片（默认是**学习答疑**）；该选择会组装下一个空白会话。

## 设置定时任务

侧栏「新建会话」下方有**定时任务**。打开后写下要做的事，选择每天或每周，选一个本地时间，选中工作区后再开始。到点后会在这个对话里做这件事；请保持 DeepSeek Harness 开着。一次性提醒仍通过 `/schedule` 或模型。
